# 선넘음 개인정보 처리방침

시행일: 2026-11-01 · 운영자: Ben App Studio (이상현) · 문의: ben.applabs@gmail.com

선넘음(이하 "서비스")은 처음 합의한 작업 범위와 고객의 새 요청을 비교해, 범위 밖일 가능성과 근거, 답장 문구를 보여 주는 도구입니다. 웹(seonneom.pages.dev)과 Android 앱이 같은 판정 서버를 씁니다. 이 방침은 둘 다에 적용됩니다.

## 1. 판정할 때 서버로 보내는 정보

| 정보 | 처리 방법 | 보관 |
|---|---|---|
| 사용자가 입력한 합의 범위(4,000자까지), 새 요청(2,000자까지), 추가 금액(선택) | 판정 버튼을 누를 때만 보냅니다. 판정 서버(Cloudflare)가 받아 AI 모델(Anthropic의 Claude)에 전달하고, 결과를 돌려준 뒤 버립니다. | 운영자 서버에는 저장하지 않습니다. 오류 기록에는 상태 코드만 남기고 입력 내용은 남기지 않습니다. |

- **입력에 고객의 실명·연락처·주민번호 같은 개인정보를 넣지 말아 주세요.** 판정에는 필요 없습니다.
- AI 모델 제공자 Anthropic은 받은 내용을 AI 학습에 쓰지 않고, 자사 정책에 따라 최대 30일 안에 삭제합니다. 자세한 내용은 [Anthropic 개인정보처리방침](https://www.anthropic.com/legal/privacy)을 따릅니다.

## 2. 개인정보 국외 이전

판정을 위해 1항의 정보가 아래 회사로 전송됩니다. 판정 버튼을 누를 때마다 인터넷(HTTPS 암호화)으로 보내집니다. 이전을 원하지 않으면 판정 기능을 쓰지 않으면 됩니다. 이 경우 판정 결과를 받을 수 없습니다.

| 받는 자 | 국가 | 목적 | 보유 기간 |
|---|---|---|---|
| Anthropic, PBC (privacy@anthropic.com) | 미국 | AI 판정 | 최대 30일(Anthropic 정책, 학습에 쓰지 않음) |
| Cloudflare, Inc. | 미국 등 Cloudflare 네트워크 | 판정 서버 운영(요청 전달) | 요청 처리 중에만. 저장하지 않음 |

## 2-1. 서버가 자동으로 보는 정보

Cloudflare는 서비스를 안전하게 운영하려고 접속 IP 주소, 브라우저·기기 종류, 요청 시각을 자체 보안 기록에 짧게 남길 수 있습니다. 운영자는 이 정보로 사용자를 식별하지 않습니다.

## 3. 기기 안에만 저장하는 정보 (Android 앱)

| 정보 | 보관 위치·기간 |
|---|---|
| 프로젝트 이름, 합의 범위, 지난 판정과 처리 상태·평가 | 이 기기의 앱 저장 공간. 사용자가 지우거나 앱을 지울 때까지 |

- 앱 안에서 프로젝트·판정을 지울 수 있고, 기록을 JSON 파일로 내보낼 수 있습니다. 내보낸 파일은 사용자가 고른 곳으로만 갑니다.

## 4. 웹 사용 통계

웹 도구는 기능이 쓰이는지 보려고 **익명 사용 통계**를 보낼 수 있습니다.

- 보내는 것: 화면 열기, 예시 채우기, 판정 요청과 결과 종류(범위 안·밖·애매함), 걸린 시간(초), 답장 복사 종류, "맞아요/틀렸어요" 평가, 오류 상태 코드
- 보내지 않는 것: 입력한 범위·요청·금액, 답장 내용, 이름·연락처, IP 주소
- 받는 곳: PostHog Inc. EU 서버. 쿠키를 쓰지 않고 IP를 저장하지 않게 설정합니다.
- 보관: 수집일부터 1개월
- Android 앱은 사용 통계를 보내지 않습니다.

## 5. 베타 신청

웹의 "베타 신청"은 운영자의 Google 설문(Google Forms)으로 연결됩니다. 신청 응답은 2026-12-09까지 모두 삭제합니다.

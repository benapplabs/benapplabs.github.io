# WorkFlow Solo 개인정보 처리방침

시행일: 2026-11-01 · 운영자: Ben App Studio (이상현) · 문의: ben.applabs@gmail.com

WorkFlow Solo(이하 "앱")는 현장 서비스 사업자가 고객·작업·사진·서명·견적·청구·입금 기록을 **이 기기 안에서만** 관리하도록 돕는 앱입니다. 앱에는 인터넷 연결 기능이 없습니다. 운영자는 앱에 입력한 어떤 정보도 받지 않습니다.

## 1. 기기 안에만 저장하는 정보

| 정보 | 예 | 보관 위치·기간 |
|---|---|---|
| 고객 정보 | 이름, 전화번호, 주소, 메모 | 이 기기의 앱 저장 공간. 사용자가 지우거나 앱을 지울 때까지 |
| 작업 기록 | 일정, 체크리스트, 작업 메모, 사용 자재 | 위와 같음 |
| 사진과 서명 | 작업 전·중·후 사진, 고객 서명 | 위와 같음. 카메라나 사진 선택 화면에서 고른 사진만 앱 저장 공간에 복사합니다. |
| 회사 정보 | 상호, 로고, 직인, 입금 계좌 | 위와 같음 |
| 견적·청구·입금 | 금액, 품목, 입금 상태 | 위와 같음 |

- 사용자가 앱에 넣는 고객 정보는 사용자(사업자)가 자기 고객에게서 받은 정보입니다. 이 정보를 수집·이용할 때 고객에게 알리고 동의를 받는 것은 사용자의 책임입니다.
- 앱에서 사진을 지워도 사진첩의 원본은 지워지지 않습니다.

## 2. 사용자가 직접 내보내는 정보

다음은 사용자가 공유 버튼을 눌러 고른 곳(카카오톡, 메일 등)으로만 나갑니다. 앱이 자동으로 보내지 않습니다.

- 작업 보고서 PDF·긴 이미지, 견적서, 청구서
- 백업 파일(앱 데이터 전체와 사진을 묶은 파일). 백업 파일에는 고객 정보가 들어 있으니 안전한 곳에 보관해 주세요.
- 전화·문자·메일·지도 열기: 기기의 해당 앱을 엽니다.

## 3. 기기 백업

Android 설정에서 기기 백업을 켜 두었다면, 앱 데이터가 사용자 본인의 Google 계정 백업에 포함될 수 있습니다. 이 백업은 Google이 관리하며 운영자는 볼 수 없습니다.

## 4. 수집해서 전송하는 정보

없습니다. 앱은 분석 통계, 광고 ID, 위치, 오류 보고를 보내지 않습니다.

## 5. 권한

| 권한 | 쓰는 이유 |
|---|---|
| 알림 | 사용자가 정한 작업 일정을 알려 줍니다. 첫 알림을 예약할 때 한 번 묻습니다. |
| 재부팅 후 실행 | 기기를 다시 켜도 일정 알림이 다시 예약되게 합니다. |
| 카메라·사진 | 카메라 앱이나 사진 선택 화면을 열 때만 씁니다. 사진첩 전체에 접근하지 않습니다. |

## 6. 제3자 제공

운영자는 정보를 받지 않으므로 제3자에게 제공하거나 판매하지 않습니다.

## 7. 사용자의 선택과 삭제

- 고객, 작업, 사진은 앱에서 하나씩 지울 수 있습니다.
- 앱을 지우거나 기기 설정에서 앱 데이터를 지우면 모든 정보가 지워집니다. 지우기 전에 필요하면 백업 파일을 만들어 두세요.

## 8. 아동

앱은 사업자용이며 만 14세 미만 아동을 대상으로 하지 않습니다.

## 9. 변경

이 방침이 바뀌면 앱 스토어 페이지나 이 페이지에 알립니다.

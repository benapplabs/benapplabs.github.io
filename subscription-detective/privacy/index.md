# 구독료 탐정 개인정보 처리방침

시행일: 2026-10-21 · 운영자: Ben App Studio (이상현) · 문의: ben.applabs@gmail.com

구독료 탐정(이하 "앱")은 사용자가 입력한 구독과 고정 지출(대출 원리금·적금 같은 자동이체 포함)로 매달 나가는 돈과 다음 결제일을 계산하고, 결제 전에 알려 주는 Android 앱입니다. 이 방침은 Android 앱에 적용됩니다. 같은 이름의 토스 미니앱은 토스 앱 안에서 따로 운영되며, 미니앱의 안내를 따릅니다.

## 1. 요약

- **회원가입이 없고, 입력한 내용을 운영자 서버로 보내지 않습니다.** 앱에는 인터넷 접속 권한이 없습니다.
- 모든 정보는 이 휴대폰 안에만 저장됩니다.
- 카드번호·계좌번호·결제 내역에 접근하지 않고, 은행·카드·대출 계좌와 연결하지 않으며, 문자 메시지를 자동으로 읽지 않습니다. 대출·적금도 사용자가 직접 입력한 금액과 날짜만 씁니다.
- 결제 전 알림은 휴대폰 안에서 예약되며, 서버를 거치지 않습니다.
- 사용 통계·광고 추적을 하지 않습니다.

## 2. 휴대폰 안에 저장하는 정보

| 정보 | 보관 위치·기간 |
|---|---|
| 항목 이름, 카테고리(대출·적금 포함), 금액, 결제 주기, 결제일, 끝나는 날(만기·상환 완료일, 선택), 무료체험 여부, 나눠 내는 사람 수 | 이 휴대폰의 앱 저장 공간. 사용자가 지우거나 앱을 지울 때까지 |
| 결제 기록(맞아요·금액이 달라요·넘기기), 구독 점검 답변, 해지 기록 | 위와 같음 |
| 알림 설정(켜기 여부, 하루 전·사흘 전) | 위와 같음 |

- 금액 변화 그래프, '금액이 달라졌어요' 안내, 월간 결산은 위 결제 기록을 휴대폰 안에서 다시 계산해 보여 주는 것이며, 따로 모으거나 보내는 정보는 없습니다.
- 사용자는 앱의 **설정 → 모든 데이터 삭제**로 언제든 모두 지울 수 있습니다. 앱을 지우면 함께 지워집니다.

## 3. 사용자가 직접 보내는 경우

- **결제 문자 공유·붙여 넣기:** 다른 앱에서 공유하거나 붙여 넣은 글은 휴대폰 안에서 가맹점 이름·금액·날짜만 찾는 데 쓰고, 원문은 저장하지 않습니다.
- **백업 파일 저장:** 사용자가 시스템 파일 창에서 고른 곳(휴대폰 저장 공간, Google 드라이브 등)에만 저장됩니다. 그 위치의 정보 처리는 해당 서비스의 방침을 따릅니다.
- **백업 내용 복사:** 백업 내용을 클립보드에 복사합니다. 붙여 넣는 곳은 사용자가 정합니다.
- **공식 안내 페이지 열기:** 해지 안내의 공식 페이지는 휴대폰의 브라우저로 엽니다. 이때 앱의 정보는 전달되지 않으며, 열린 페이지의 정보 처리는 해당 사이트의 방침을 따릅니다.

## 4. Android 자동 백업

Android의 자동 백업을 켜 둔 경우, 앱의 항목 저장 파일이 **사용자 본인의 Google 계정 백업**에 포함되어 새 휴대폰으로 옮길 수 있습니다. 이 백업은 Google이 사용자 계정에 보관하며 운영자는 볼 수 없습니다. 휴대폰의 설정에서 백업을 끌 수 있습니다.

## 5. 권한

| 권한 | 목적 |
|---|---|
| 알림 | 결제 전·무료체험 종료 전 알림. 사용자가 알림을 켜기로 고른 뒤에만 묻습니다. 거부해도 다른 기능은 그대로 쓸 수 있습니다. |
| 부팅 완료 수신 | 휴대폰을 다시 켠 뒤 예약한 알림을 다시 만듭니다. |
| 진동 | 알림을 받을 때 진동합니다. |

## 6. 제3자 제공·국외 이전

운영자는 사용자 정보를 받지 않으므로, 제3자에게 제공하거나 국외로 이전하거나 판매하지 않습니다.

## 7. 아동

앱은 만 14세 미만 아동을 대상으로 하지 않습니다.

## 8. 알려 드려요

- 결제일·금액은 사용자가 입력한 내용으로 계산한 예상값입니다. 실제 결제는 카드사·서비스의 안내를 확인해 주세요.
- 앱은 해지를 대신 처리하지 않습니다.

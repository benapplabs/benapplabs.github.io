# 콕찾기 개인정보 처리방침

시행일: 2026-10-13 (2026-10-15 앱 이름 변경: 캡처찾기 → 콕찾기) · 운영자: Ben App Studio (이상현) · 문의: ben.applabs@gmail.com

콕찾기(이하 "앱", 이전 이름 캡처찾기·Screenshot AI)는 사용자가 고른 사진(서류 사진, 스크린샷, 받은 캡처 등)을 **이 기기 안에서만** 저장하고 글자를 인식해 검색할 수 있게 해 주는 앱입니다. 앱은 사진과 사진 속 글자를 운영자 서버로 보내지 않습니다.

## 1. 기기 안에서만 처리하는 정보

| 정보 | 처리 방법 | 보관 위치·기간 |
|---|---|---|
| 사용자가 고른 사진의 사본 | 사진 선택 화면에서 고른 사진만 앱 전용 저장 공간에 복사합니다. 사용자가 자르기를 하면 자른 사진을 저장합니다. 사진첩 전체에 접근하지 않습니다. | 이 기기의 앱 저장 공간. 사용자가 삭제하거나 앱을 지울 때까지 |
| 사진 속 글자(인식 결과), 제목, 태그 | Google ML Kit의 **기기 내** 글자 인식으로 만듭니다. 인식은 인터넷 없이 기기에서 이루어집니다. | 위와 같음 |
| 목록용 작은 미리보기 이미지 | 사진 사본에서 만듭니다. | 위와 같음 |

- 앱에서 사진을 지워도 **사진첩의 원본은 지워지지 않습니다.**
- 이 정보는 기기 백업과 기기 간 데이터 이전에서 제외되어 있습니다. 새 기기로 옮겨지지 않습니다.

## 2. 수집해서 전송하는 정보: 익명 사용 통계

앱을 개선하고 베타 성과를 판단하려고 **익명 사용 통계**를 보냅니다.

- **보내는 것**: 앱 열기, 사진 가져오기 결과(개수만), 글자 인식 성공·실패, 검색 횟수와 검색어 **글자 수**·결과 **개수**, 결과 열기, 편집·삭제 같은 **사용 동작**과 그 시각, 앱 버전, 운영체제 종류, 설치할 때 무작위로 만든 **설치 ID**
- **보내지 않는 것**: 사진, 사진 속 글자, 검색어, 제목, 태그, 이름·전화번호·이메일, 광고 ID, 기기 고유번호, 위치
- **받는 곳**: PostHog Inc.의 EU(유럽연합) 서버(분석 서비스). 전송 중에는 암호화(HTTPS)됩니다. IP 주소로 위치를 추정하지 않도록 설정하고, IP 주소는 저장하지 않도록 설정합니다.
- **목적**: 기능 사용 여부와 오류 파악, 서비스 개선
- **보관 기간**: 수집일부터 1개월이 지나면 삭제
- 설치 ID는 앱을 지우거나 앱 데이터를 지우면 새로 만들어집니다. 이전 통계와 다시 연결되지 않습니다.

## 3. Google ML Kit가 Google에 보내는 정보

글자 인식에 쓰는 Google ML Kit는 기능 개선을 위해 **사진이나 인식된 글자가 아닌** 기기·앱 정보와 성능 지표(예: 처리 시간, 오류)를 Google에 보낼 수 있습니다. 자세한 내용은 [Google ML Kit의 데이터 공개 안내](https://developers.google.com/ml-kit/android-data-disclosure)와 [Google 개인정보처리방침](https://policies.google.com/privacy)을 따릅니다.

## 4. 제3자 제공

법령에 따른 경우를 빼고 위 2·3항 외에 개인정보를 제3자에게 제공하거나 판매하지 않습니다.

## 5. 사용자의 선택과 삭제

- 앱에서 사진을 하나씩, 또는 **모든 항목 삭제**로 한 번에 지울 수 있습니다.
- 앱을 지우거나 기기 설정에서 앱 데이터를 지우면 사진 사본, 인식 결과, 설치 ID, 아직 보내지 않은 통계가 모두 지워집니다.
- 이미 보낸 익명 통계의 삭제를 원하시면 ben.applabs@gmail.com으로 알려 주세요. 다만 통계에는 사용자를 알아볼 정보가 없어 특정 사용자의 통계를 골라내기 어려울 수 있습니다.
